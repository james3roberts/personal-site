JRC — Websites for Real Small Businesses

This is the website for JRC (Jim Roberts Construction), a small web-services business based in Colorado Springs.

I'm building this business around a simple idea: small businesses shouldn't need a huge budget or a giant agency to get a good website.

I build clean, practical websites that help businesses look professional and make it easy for customers to find them and get in touch.

This repository contains the JRC website and the work I'm doing to build the business.

What I'm Building
Starter websites for small businesses
Larger business websites
Custom/pro-level websites
Website maintenance and ongoing support
Eventually, reusable templates that let me build sites faster
About the Project

I'm a computer science graduate making the transition from construction and equipment work into software and web development. JRC is where I'm putting those skills to work.

This isn't meant to be a perfect project built in a vacuum. I'm building it, testing it, putting it in front of real people, and improving it as I go.
